## 一、三个云函数

| 函数名 | 触发路径 | 运行环境 | 内存 | 端口 | 超时 | 代码位置 |
|---|---|---|---|---|---|---|
| health | `/api/health` | Node.js 20.19 | 256MB | 9000 | 默认 | 平台自带/早期建，代码不在本仓库 |
| plan-days | `/api/plan-days` | Node.js 20.19 | 256MB | 9000 | **60 秒** | `cloudfunctions/plan-days/` |
| checkin（注意：控制台里叫这个名字，少个 s） | `/api/checkins` | Node.js 20.19 | 256MB | 9000 | **30 秒** | `cloudfunctions/checkins/` |

建的方式：云函数 → 新建 ∨ → **通过代码包创建** → 上传 zip（不是「静态网站托管」那个上传，也不是模板创建）。

## 二、环境变量（只记名字，值不写进来）

- 名：`TCB_ACCESS_TOKEN`，值 = 控制台建的「服务端 API Key」（不是客户端 Publishable Key）
- 位置：函数详情 → 函数配置 → 环境变量
- **值存在本机 `Vibe coding/_local/密钥/锚点-访问密钥.txt`，该目录已在 .gitignore 里，永不入库**

连库方式：**不走 pg 驱动 TCP 直连**（这台环境是共享集群，外网地址不给开、内网互联也不支持，直连必然失败），走平台自带的数据通道：

```
https://<环境ID>.api.tcloudbasegateway.com/v1/rdb/rest/<表名>
```

## 五、2026-10-03 踩过并记录在案的坑

1. **pg 直连走不通**：共享集群不给开外网、也不支持内网互联 → 改走数据网关（HTTP）
2. **checkins.date 是外键指向 plan_days(date)**：没排计划的那天写不进打卡，接口要提前查并返回 400 中文说明
3. **打包脚本曾经失效**：表名写在 `BASE + '/plan_days?'` 这个字符串里，替换要命中这一处（脚本已修）
4. **网关直连的那把 API Key 会突然失效（401）**：云函数内部那份仍能用。**现阶段远程改库可能不可用**，必要时在控制台重建 API Key 并替换环境变量
