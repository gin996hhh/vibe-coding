## 三、它们在产品里怎么用

三环结构各接一个内容源（详见 `产品理念-2026-10-02.md`）：

- **状态环（身体状态）** ← Huberman 47 条协议。用户打卡的睡眠 / 精力 / 心情三个 1–5 分，用来选对应状态下该做什么。
- **方法环（具体做什么）** ← 《高性价比人生指南》650 条。按成本标签筛选，其中「毅力 = 否」的有 337 条——这一批是状态低时也能做的，优先推。
- **频率环（做多少次）** ← 产品自身的交互次数设计，不依赖外部内容源。
