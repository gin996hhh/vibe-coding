四、最小修复

改了哪个文件：today.html（唯一一个文件）

改了什么：第 556 行调用 Today.buildAnchors(picked, t, lastAnchorTexts(t)) 时，
　　　　　t 这个变量在 IIFE 顶层从来没定义过——它只在 today.html 的四个函数内部
　　　　　（175 / 394 / 425 / 490 行）各自定义过。第 515 行那个调用在函数内所以没事，
　　　　　556 行这个在按钮回调里（顶层），一点击就崩。
　　　　　修法是在调用前补一行 var t = Store.todayStr();，与文件里其余四处写法一致。

为什么只改这一处：清单明令「只修复一个最大阻塞点」「不要按反馈大改版」「不要一口气全改」。
　　　　　　　　　所以没动样式、没动其他页面，也没顺手重构那四处重复的 var t。

修复前那行：var anchors = Today.buildAnchors(picked, t, lastAnchorTexts(t));
修复后：　　var t = Store.todayStr();
　　　　　　var anchors = Today.buildAnchors(picked, t, lastAnchorTexts(t));

验证到哪一步：语法检查 OK；Store.todayStr 是对外导出的（store.js:162）且在作用域内
　　　　　　　（today.html 里另有 16 处 Store. 用法）；计算层 node 直跑 4 项全过
　　　　　　　（早晚锚点生成得出 / 避开昨天那条 / 同输入结果稳定 / 低状态也生成得出）。
　　　　　　　浏览器里的真实点击由测试者本人在本地服务 http://localhost:8000/today.html 复测确认。
