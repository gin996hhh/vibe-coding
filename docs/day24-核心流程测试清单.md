## 找到的问题（按影响排序）

**1 号：新建计划这条路是断的（最影响核心流程）**
- 现象：契约 §4 登记了 POST /api/plan-days（新建某天的计划），代码里没实现，实测 405。
- 连带后果：写体检必须先有计划行（外键约束），没计划行就报 PLAN_DAY_NOT_FOUND；而页面上任何一个地方都建不了计划行。结果是：新用户打开记录台，没有任何一天能打卡。
- 复现步骤：POST /api/plan-days 任意日期 → 405；再 POST /api/checkins 一个库里没有的日期 → 400 PLAN_DAY_NOT_FOUND。
- 已尝试动作：翻过 `cloudfunctions/plan-days/index.js`，只实现了 GET / PATCH / DELETE 三个分支，没有 POST；翻过契约 §4，这一条从 Day 15 登记至今标着「已实现」，实际没做。
- 影响：核心流程第一步就断，新用户完全用不了。

**2 号：只有计划行、没内容的天在列表里看不见**
- 现象：`js/records.js` 的 `hasContent()` 要求有体检 / 勾了完成 / 写过复盘，占一个才进列表。
- 后果：建了计划但还没开始的那天，在记录台上找不到，也没法点进去改。
- 备注：这一条 1 号修好后才会真正暴露（现在建不了计划，所以暂时看不到）。

**3 号（记录，不今天修）：记录台上的调试信息、复盘入口重复、回收站入口不见了**
