# 前端设计规则

本文件是「锚点」全站视觉的唯一裁判。做界面改动前先按它审一遍，改完按它自查一遍。

## 页面层级
- 每个页面只有一个主标题（`h1`），区块标题用 `h2`，不许跳过层级
- 区块之间靠间距分组，不靠加边框和分隔线
- 说明性文字（`.muted`）不承担主要信息，主要信息必须有正常对比度的文字

## 颜色：蓝调时刻
- 全站色板只在 `css/style.css` 的 `:root` 里定义一次；页面、JS、内联 style 里不许写死色值
- 语义固定：暖橙 `--ember` **只给「已完成 / 做到」**，其他地方一律蓝灰，不许拿橙色做装饰
- 对比度（深色底上的硬要求）：
  - 正文与次级文字 ≥ 4.5:1
  - 12–13px 的三级文字 `--ink-3` 在 `--card` / `--card-hi` 底上也不得低于 4.5:1
  - 白字放在 `--sky-deep` 主按钮上 ≥ 4.5:1
- 报错只用 `--danger`

## 字体与字号
- 正文 16px；次级 14px；三级文字与说明 13px 起，**任何可见文字不低于 12px**
- 区块标题 `h2` ≥ 17px；页面主标题 `h1` 26px
- 关键数字可以到 28px，但同屏不能出现两个同级大数字抢焦点

## 间距
- 卡片内边距 18px，卡片间距 16px
- 同一层级的块间距必须取同一档（8 / 12 / 16 / 22px），**不许出现 10、11、15 这类随手值**
- 不同层级的间距要能一眼看出差别，否则分组失效

## 卡片与按钮
- 按钮必须有三种状态：默认、悬停、**禁用（`:disabled`）**
- 禁用态要明确"不可点"：降低不透明度或用灰底 + `cursor: not-allowed`，不能只有 hover 态
- 输入框必须有可见的 focus 样式，错误态用 `--danger` 边框 + 文字提示
- 卡片内的操作按钮要在卡片内边距内，不许顶到边缘

## 移动端（360px）
- 360px 宽度下不能出现横向滚动
- 长串英文、数字、URL 必须 `overflow-wrap: anywhere`
- 导航在小屏允许换行，不许隐藏、不做汉堡菜单
- 触控目标（按钮、可点整块）高度不小于 40px

## 修改前
- 先列出具体问题清单，每条给出：文件名 + 位置 + 现象 + 为什么算问题
- 再逐个修复，**一次只改一个**，不足就如实说不足，不编凑数

## 修改后
- 桌面宽度和手机宽度（360px）各看一遍
- 确认交互（点击、勾选、保存、跳转）没有因为改样式而失效
- 页面控制台无报错，无横向溢出
